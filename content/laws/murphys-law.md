## Origin

Edward A. Murphy Jr. was an Air Force engineer working on Project MX-981 at Edwards Air Force Base in 1949 — rocket-sled runs measuring how much deceleration a human body could take. Sixteen strain gauges were installed on the harness, every one of them wired backwards, and a run that should have produced data produced zeros. Murphy's remark about the technician was rephrased by the project manager, George Nichols, and repeated to reporters by John Stapp, the doctor riding the sled. In its original engineering sense it was a design rule, not a lament: if a part can be installed wrong, someone will install it wrong, so build the part so it only fits one way.

## Mechanism

With enough repeated exposure, even a rare failure mode becomes increasingly likely. A system of many interacting parts has far more ways to be wrong than right, and the count of failure modes grows faster than the part count because parts fail in combination. Memory then does the rest: successful runs are unremarkable and forgotten, while failures are recalled, so the rate can feel higher than it is.

## Where it breaks

Read as fatalism it inverts its own origin. Murphy's point was that a part which can be assembled wrongly eventually will be, so the fix is a part that only fits one way — the law is a design instruction, not a prediction that the universe is hostile. It is also not a probability claim: memory keeps failures and discards many uneventful runs, so the felt rate can be higher than the measured one.

## Example

The Mars Climate Orbiter was lost in September 1999 because Lockheed Martin's ground software reported thruster impulse in pound-force seconds and NASA's navigation software read the same numbers as newton-seconds. Nothing malfunctioned. The interface accepted both readings as plausible, the discrepancy accumulated over nine months of cruise, and the $125 million spacecraft entered the Martian atmosphere about 100 kilometres lower than planned and broke up.
